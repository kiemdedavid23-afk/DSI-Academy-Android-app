# C5 — Espaces et fil d'activité

Source : RAPPORT-INTEGRATION-WORKER-COMMUNAUTE.md (§11.6, §11.7, §15 n°14) ; site : `CommunitySpacesPage`, `CommunitySpacePage`, `CommunityCreateSpacePage`, `spaces.service`, `activityFeed.service`.

## Règles relues
R-NET-1 (aucune adresse), R-LAY-4/5/6 (écrans sans API ; stores seuls), R-DATA-1/2/3, R-UI-1, R-SEC-4 (stores purgés), R-I18N-1, R-TEST-LOC.

## Contenu
- `core/api/endpoints/community/spaces.*` : liste (recherche `q`), détail, création, rejoindre, quitter.
- `core/api/endpoints/community/activity.*` : fil global.
- `features/community/store/` : `spacesStore` (liste + recherche), `spaceStore` (détail par espace), `spaceActions` (rejoindre, quitter, créer), `activityStore`.
- `features/community/screens/` : Espaces, Espace, Nouvel espace, Activité.
- `features/community/spaceImages.ts` : visuels space-1 à 3 du site.
- `CommunityStack.tsx` : routes `Spaces`, `Space`, `NewSpace`, `Activity` ; `Chat` accepte le type `space`.
- Accueil : entrées « Espaces » et « Activité ». Discussions : filtre « Espaces » et conversations de type `space`.

## Choix
1. **Création toujours publique** : un espace privé est créable mais inutilisable (§11.6) ; rien ne le propose.
2. **Propriétaire** : badge à la place du bouton Quitter (il ne peut pas quitter). Message « propriétaire » si le Worker répond quand même ACCESS_DENIED.
3. **Rejoindre un espace privé** (ACCESS_DENIED) : message « Cet espace est privé », comme le site. Détail privé non rejoint : même message ; espace inconnu : « introuvable ».
4. **Déjà membre** : la réponse n'a pas de `conversationId` ; le détail est relu après chaque rejoindre ou quitter, c'est lui qui donne le bouton « Ouvrir la discussion ».
5. **Fil d'activité** : la phrase est fabriquée dans l'app (FR/EN) à partir du type et de l'acteur ; le `text` du serveur n'est jamais affiché ni stocké. Un type inconnu est écarté. Nom affiché vide : pseudonyme, puis « Un membre ».
6. **Débit** : pas de sondage des espaces ni du fil (rapport : pas de temps réel). Relecture à l'ouverture, après une action, ou en tirant vers le bas (fil). Recherche avec délai de 300 ms ; une réponse plus ancienne n'écrase jamais la plus récente.
7. **Écritures jamais rejouées automatiquement** (rejoindre, quitter, créer).
8. Les conversations d'espace s'ouvrent dans l'écran Discussion de C4 (même relecture 5 s, même envoi sans rejeu, auteurs affichés comme dans un groupe).

## Non couvert
Liste des membres d'un espace, gestion d'un espace, espaces privés, pièces jointes : absents du Worker.
