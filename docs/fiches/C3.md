# C3 — Annuaire, contacts, blocage

Source : RAPPORT-INTEGRATION-WORKER-COMMUNAUTE.md (§3.4, §3.5, §11.3, §11.4) ; site : `CommunityFindMemberPage`, `CommunityMemberPage`, `CommunityContactsPage`, `directory.service`, `contacts.service`.

## Règles relues
R-NET-1 (aucune adresse), R-LAY-4/5/6 (écrans sans API ; stores et actions seuls à parler à `core/api`), R-DATA-2/3, R-UI-1 (chargement, vide, erreur, succès), R-SEC-4 (stores purgés), R-I18N-1 (clés du site déjà présentes), R-TEST-LOC.

## Contenu
- `core/api/endpoints/community/` : `directory.*` (recherche, fiche), `contacts.*` (liste, demandes, demander, accepter, refuser, annuler, retirer, bloquer, débloquer) ; `CommunityPeer` et `mapPeer` partagés.
- `features/community/store/` : recherche et fiches, contacts (store de ressource), actions.
- `features/community/components/` : `CommunityGate` (profil + abonnement requis), `PersonRow`.
- `features/community/screens/` : Accueil, Trouver un membre, Fiche membre, Contacts.
- `app/navigation/house-stacks/CommunityStack.tsx` : remplace le placeholder (Home, Find, Contacts, Member).

## Décisions appliquées
- **D7** : `blocked.byThem` n'est jamais lu ni affiché ; seul `byMe` pilote l'écran. Un blocage subi apparaît par le message neutre du Worker (`INTERACTION_UNAVAILABLE`).
- **D8** : le site suit le contrat 1.8.0 ; l'app suit le rapport (1.11.x). Vérifié ici : l'identifiant d'une demande est `id` (pas `relationId`) dans `GET /contacts/requests`.
- Création du profil : jamais dans la Communauté. `CommunityGate` renvoie vers la page Profil de l'espace membre.

## Choix
1. La demande part avec `userId` (identifiant DSI) ; le pseudonyme sert uniquement à ouvrir la fiche.
2. Les quatre issues d'une demande (créée, déjà envoyée, croisée acceptée d'office, déjà contacts) ont chacune leur message.
3. « Écrire » et « Appeler » ne sont pas dans C3 : ils arrivent avec les discussions (C4) et les appels (C7).
4. Pas de liste des blocages côté Worker : le blocage se lit sur la fiche (`byMe`), rien n'est mémorisé dans l'app.
5. Confirmation (boîte système) avant blocage et retrait.
6. Recherche : une réponse plus ancienne ne remplace jamais la plus récente.
